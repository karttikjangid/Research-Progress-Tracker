# The Daily Cognitive Budget
To prevent the inevitable burnout of a 12-hour sprint, my daily limits are strictly gated by cognitive capacity, not sheer willpower. 

**The 4+2+2 Structure**:
- **4 Hours [Deep Strain]**: Maximum-effort mathematical derivations (20 to 45-minute strict struggle timers), paper decoding, and adversarial NumPy/PyTorch from-scratch verification. 
- **2 Hours [GSoC Continuity]**: Active container optimization and C++ dataset abstraction refactoring for JdeRobot. This doubles as the open-source scouting mechanism for European labs.
- **2 Hours [Low-Intensity Input]**: Reading documentation, passive review, or code auditing.
- **15 Minutes [Vocal Drill]**: The 5-minute recorded monologue and subsequent transcript audit.

**Agent Rule**: When chunking tasks or generating daily agendas, Claude Code must rigorously enforce these time boundaries and warn me if a suggested task breaches the 4-hour high-strain limit.
